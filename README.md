# GenLab - Webcraft Challenge

This project is my submission for the **Webcraft Challenge** organized by **GenLab**.

## Objective
The goal was to replicate the high-fidelity splash screen and hero section of the site provided during the challenge: [Farm Minerals Promo](https://www.farmminerals.com/promo).

## Key Features
- **Cinematic Splash Screen:** Sequence-accurate animation using GSAP, featuring layered box drops and a four-part sequential logo reveal.
- **Hero Section:** Responsive layout with navigation, a large typographic title, and a sub-bar.
- **3D Asset:** A custom-built 3D rotating tablet element with the GenLab icon.
- **Interactive Hover:** A pixelated gradient hover effect at the bottom of the hero section.

## Tech Stack
- HTML5
- Vanilla CSS
- JavaScript (Vanilla)
- GSAP (GreenSock Animation Platform)
